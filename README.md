# ПР5, вариант Б в CoppeliaSim: обход препятствий в мини-лабиринте

Модель нужна для отладки алгоритма до испытаний на реальном роботе или вместо них, если робота нет.
Робот тот же, что в ПР4 (Pioneer P3-DX). Программа повторяет функцию `avoidObstacles()` из листинга 2
строка в строку: автомат FORWARD → BACKWARD → TURN, медиана трёх измерений, параметры варианта из таблицы 6.

## Файлы

| Файл | Зачем |
| --- | --- |
| `build_maze.py` | строит лабиринт 3,6 × 3,6 м вокруг робота и сохраняет сцену `pr5_maze.ttt` |
| `pr5_maze.py` | обход препятствий: автомат состояний, подсчёт касаний и застреваний, графики |

Оба файла кладутся в одну папку (`pr5_maze.py` берёт план лабиринта из `build_maze.py`).
В `pr5_maze.py` меняйте **только блок «ИСХОДНЫЕ ДАННЫЕ ВАРИАНТА»**.

## Лабиринт

```
+-----------------------------------+
|                       |       /   |   / - стенка под 45° (испытание Б2)
|  карман     o ножка   |     /     |   o - ножка стула d = 4 см (испытание Б3)
|                       |  карман   |
|-----------+                       |
|                                   |
|  ( ) ведро      S                 |   S - старт робота
|                       +-----------|
|           |                       |
|  карман   |  [ ] коробка   . банка|
|           |                       |
+-----------------------------------+
```

Клетка 1,2 м: Pioneer крупнее учебного шасси (0,45 × 0,38 м), поэтому полигон 1,5 × 1,5 м из методички
увеличен примерно вдвое. Стены «вертушкой» образуют четыре тупиковых кармана — в них хорошо видно,
как работает стратегия поворота. Размеры и положение препятствий задаются списками `WALLS`, `POSTS`, `BOXES`
в начале `build_maze.py`.

## Порядок работы

Установка — как в ПР4 (тот же `~/pr4env`). Каждый раз: CoppeliaSim в терминале 1, `source ~/pr4env/bin/activate` в терминале 2.

| № | Действие | Где | Результат |
| --- | --- | --- | --- |
| 1 | Открыть `pr4_diff.ttt` из ПР4 (или новая сцена + robots → mobile → pioneer p3dx) | CoppeliaSim | робот в сцене |
| 2 | `python3 build_maze.py` | терминал 2 | лабиринт построен, сохранена `pr5_maze.ttt` |
| 3 | Вписать параметры своего варианта в `pr5_maze.py` | редактор | — |
| 4 | `python3 pr5_maze.py` | терминал 2 | 2 мин модельного времени (~0,5–1 мин реального), итог Б4 в консоли |
| 5 | Закрыть окна графиков | — | программа завершилась |

Файлы для отчёта: `maze_path.png` (траектория на плане), `maze_dist.png` (показания дальномера и состояние автомата), `maze_log.csv` (журнал по шагам).

**Испытания Б1–Б3.** Мышью поставьте робота перед стеной, стенкой под 45° или ножкой стула (симуляция остановлена),
задайте `T_RUN = 10` и запустите `pr5_maze.py`. Расстояние после остановки печатается в консоли.
Чтобы вернуть робота в центр — откройте `pr5_maze.ttt` заново.

## Чем модель отличается от реального робота

| Реальный робот (листинг 2) | Модель |
| --- | --- |
| HC-SR04 спереди | 4 передних сонара Pioneer (±10° и ±30° от курса, параметр `CONE = 35`) — программа находит их сама. Pioneer намного шире учебного шасси, и одного узкого луча ему мало: при `CONE = 15` (только ±10°) робот начинает задевать торцы стен углами корпуса — хороший опыт для раздела «Выводы» |
| ШИМ 0…255 на L298N | ШИМ пересчитывается в скорость колеса: 255 → `V_MAX` = 0,5 м/с |
| период цикла `DT` = 60 мс | шаг симуляции 50 мс |
| касание видно глазами | касание считает CoppeliaSim (`sim.checkCollision`) |

Стратегия «осмотр» (варианты 4, 7, 10, 13) в программе не реализована — это задание п. 5.5,
доработайте ветку `TURN` так же, как на Arduino.

## Если что-то не так

| Симптом | Что сделать |
| --- | --- |
| `В сцене нет лабиринта` | открыть `pr5_maze.ttt` или запустить `build_maze.py` |
| `Робот не найден` | перетащить pioneer p3dx в сцену, повторить `build_maze.py` |
| `У Pioneer остался встроенный Script` | удалить Script из модели (или повторить `build_maze.py` — он удаляет сам) |
| `ModuleNotFoundError: build_maze` | `build_maze.py` должен лежать рядом с `pr5_maze.py` |
| Робот задевает торец стены или ножку стула | это не ошибка программы: узкие препятствия плохо видны сонару (испытание Б3). Опишите в выводах, сравните с `CONE = 15` |
| Робот ездит сам ещё до запуска `pr5_maze.py` | в сцене остался Script Pioneer — повторить `build_maze.py` |
| `CoppeliaSim не отвечает 15 с` | как в ПР4: Stop, при необходимости перезапустить CoppeliaSim |
